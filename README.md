# Kartik Chawla - Developer Portfolio

Welcome to my personal developer portfolio! This site is built with a striking neo-brutalism aesthetic and features an interactive retro terminal.

## Features
- **Neo-Brutalism Design:** Bold colors, sharp contrasting borders, and micro-interactions for a modern, unique feel.
- **Interactive Terminal:** An integrated, fully-functional web terminal where you can run commands to explore my resume, projects, and skills.
- **Responsive Layout:** fully optimized for both desktop and mobile viewing.

## Tech Stack
- HTML5
- CSS3 (Custom Neo-Brutalism System)
- Vanilla JavaScript
